# Data

This directory contains the data used for the UN General Assembly voting analysis.

## Directory structure

```text
data/
├── raw/
│   ├── 2026_02_06_ga_voting.csv
│   ├── country_codes.csv
│   ├── Matches.csv
│   ├── un_votes.csv
│   └── un_votes_2025.csv
│
└── processed/
    ├── BetaSummary.csv
    └── ThetaSummary.csv
```

## Raw data

The `raw/` directory contains the original datasets used as inputs to the analysis.

These files contain information on:

* UN General Assembly votes;
* countries and country codes;
* resolutions and resolution identifiers;
* voting sessions;
* additional matching information used during data preparation.

The raw datasets are **not tracked by Git** because some files exceed GitHub's file-size limit. They must therefore be obtained separately and placed in:

```text
un_voting_analysis/data/raw/
```

The analysis expects the files to have the names shown above.

## Processed data

The `processed/` directory contains outputs generated by the Bayesian voting model.

### `ThetaSummary.csv`

Contains the estimated country-level ideological positions over time.

These estimates are produced from the posterior distribution of the model's `theta` parameters and are used by the visualization functions to analyse ideological trajectories and distances between countries.

### `BetaSummary.csv`

Contains the estimated resolution-level parameters.

These parameters capture the characteristics of individual UN resolutions and are extracted from the posterior distribution after MCMC sampling.

Both files are generated by `main.ipynb` and can be reused for visualization and subsequent analysis without rerunning the full Bayesian model.

## Reproducibility
We were not able tu put our data on the repository because they where too large.

To reproduce the analysis:

1. Obtain the required raw datasets.
2. Place them in `un_voting_analysis/data/raw/`.
3. Install the dependencies listed in the repository's `requirements.txt`.
4. Run `un_voting_analysis/main.ipynb`.

The notebook performs the data preparation, model construction, MCMC sampling, posterior summarization, and visualization.
